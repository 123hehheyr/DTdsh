# Agent Note: 组合包与插件展示元信息

Status: implemented

[English](2026-09-28-bundle-and-plugin-display-metadata.md) | 中文

## 问题

一个包可以导出多个插件。它的 npm 介绍和图片标识整个包，不一定适用于每个导出的插件。展示文本也必须在激活前及插件加载失败后保持可用。

## 决策

普通插件复用导出 locale JSON 中的 `meta.title` 和 `meta.description`，不为展示文本或自定义图片读取包清单。[本地化元信息决策](2026-09-18-localized-package-metadata.zh.md)继续约束 locale 资源身份、英文发现入口、逐字段语言回退、诊断与不激活读取；本文取代其中普通插件的包字段回退。

组合包使用相同的 locale 资源，还可以读取导出的包清单文本和独立的 `./icon` 资源。Node exports 选择 locale 与图标路径，因此作者可以移动资源而不改变公开的资源地址。图标不需要顶层清单字段，也不要求导出 `package.json`。[包开发指南](../../../../docs/cookbook/adding-a-package.zh.md#plugin-display-metadata)负责说明作者格式与图片限制。

管理器传入它已经解析出的组合包目录。路径限制使用包的真实根目录，而不是图标目录或 locale 目录：平行的资源目录有效，指向包外的符号链接无效。图标导出可以缺失；目标无效或选中的文件不可读时返回诊断，不丢弃有效文本。普通插件行及其详情使用通用插画。

元信息查询不执行插件入口。禁用或加载失败的插件仍保留 locale 文本，每个完整插件模块名及其解析父地址保持独立的资源身份。发布检查同时验证普通插件 locale、组合包 locale、选中的图片资源及发布文件覆盖。

## 考虑过的替代方案

**导出 JavaScript `meta` 值。** 读取它需要执行模块，使元信息依赖加载。现有 locale JSON 已支持禁用插件和独立的子路径元信息。

**为所有插件使用包元信息。** 包级介绍或图片不一定描述它导出的每个插件。普通插件拥有自己的 locale 文本，组合包拥有包级展示资源。

**保留顶层 `icon` 路径。** 它在现有资源导出机制之外增加一处路径声明。固定的 `./icon` 地址与 locale 资源使用相同的 Node 解析和重定向方式。

**要求图标同时导出清单。** 文本回退和图片发布相互独立。已经解析的组合包根目录无需暴露另一项资源即可提供路径限制。

## 验证

针对性读取器和发布测试覆盖重定向与条件目标、缺失导出、无效资源、大小限制、路径限制，以及普通插件只读 locale 的行为。消费方和浏览器测试覆盖禁用行的本地化文本、组合包图片、普通插件通用插画和保留的诊断。

## 影响

组合包作者将顶层 `icon` 声明替换为 `exports["./icon"]`，并将目标加入 `files`。普通插件作者若希望插件行显示包描述文本，应将其发布到 locale `meta.description`；否则不显示描述。Host 不额外执行 JavaScript，也不需要 Cordis 或 Loader 元信息 API。Session 日志和管理工具的展示字段排除规则保持不变。
