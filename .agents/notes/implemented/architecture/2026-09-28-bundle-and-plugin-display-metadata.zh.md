# Agent Note: 组合包与插件的展示元信息

Status: implemented

[English](2026-09-28-bundle-and-plugin-display-metadata.md) | 中文

## 问题

Cordis 插件可以是模块命名空间、函数或服务类，不一定拥有 npm 包。为每个插件读取 manifest，会把包级介绍与图标分配给可能代表同包中不同功能的条目。

## 决策

组合包拥有包级展示资源与自定义图标。普通插件通过已加载插件对象的 `meta` 属性提供可选标题与描述：函数插件命名空间使用命名导出，默认导出的服务类使用静态属性。每个字段沿用字面字符串或包含英文回退值的语言映射形式。[添加包实操手册](../../../../docs/cookbook/adding-a-package.zh.md#plugin-display-metadata)维护编写示例。

每个 Cordis fiber 保留注册时传入的解包插件。Loader 暴露当前存活根 fiber 的插件，因此 HMR 替换和回滚会暴露对应的元信息。清单仅从该对象投影标题与描述，包括已挂载的预设条目。读取不会导入插件、解析其 locale 资源或打开其 manifest。未加载的条目没有元信息，模块名仍作为展示回退值。等待依赖或保留激活错误的已加载条目仍可提供文本。普通插件响应与行中不包含图标。

组合包禁用时仍可读取其元信息。导出的 `locale/en.json` 作为语言发现入口；各字段独立回退到可访问的组合包 manifest，再回退到完整名称且不显示描述。资源解析遵循包 exports 与调用方的解析基准。文件地址形式的元信息请求不探查相邻资源。无效的 locale 或图标文件保留诊断与管理入口。图标读取器为 manifest 目录内受支持的图片返回 data URL，符号链接解析后也必须位于该目录内。

Client 使用现有的语言选择。完整模块名、条目 id、搜索身份与操作目标仍是技术身份。设置页可缩短字面的技术名回退值，翻译标题保持原样。插件没有描述时仍可使用配置摘要。注册表安装预览、面向模型的管理输出与 Session 事件不接收多语言 UI 字典。

本决策替代[部分被替代的元信息决策](2026-09-18-localized-package-metadata.zh.md)中的普通插件资源查询，并保留其组合包资源规则。内置组合包文案仍放在导出的 locale 文件中，不在管理器中维护词典。发布检查仅验证组合包的元信息资源与图标。

## 考虑过的替代方案

**要求每个插件拥有 manifest。** 子路径和本地模块都是有效的 Cordis 插件；包归属不属于加载接口。

**导入禁用插件以读取导出。** 导入会执行模块初始化。打开或刷新管理页不得执行原本禁用的插件。

**读取相邻 locale 文件或为插件行缓存包元信息。** 编译产物布局和包名无法标识单个插件的行为。保留实际加载的对象可维持各条目的身份，避免额外的缓存失效策略。

**激活时注册展示文本。** 等待依赖的插件虽然已加载模块，却无法提供元信息。被动的导出值不依赖服务就绪状态。

**增加另一套语言回退策略或为预览下载包。** 现有 locale 选择已覆盖展示文本，注册表预览不需要额外执行或下载包。

## 验证

针对性测试覆盖已加载命名空间与服务的元信息、等待及失败条目、禁用后重新启用的对象替换、HMR 替换与回滚、预设投影、profile 树中的行身份，以及普通行不读取 manifest。组合包测试保留 locale 回退与图标验证。Client 和浏览器测试区分组合包插画与普通插件行。发布测试拒绝无效组合包资源，同时忽略无关插件资源。

## 影响

禁用或其他未加载的插件显示模块名，即使其源码导出了元信息。作者需将普通插件介绍从 JSON 资源迁移到 `meta`；只有组合包可以提供自定义图标。
